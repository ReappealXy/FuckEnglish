# FuckEnglish 0.1.7

本次改进背词窗口与键盘操作，并修复下拉菜单透明度。

- 背词窗口正常显示时不再占用 Windows 任务栏按钮，程序继续常驻托盘。
- 标题栏最小化按钮左侧增加图钉，可开启或取消窗口置顶；本次运行中切换胶囊后保留状态。
- 英选中支持数字键 1、2、3、4，对应左上、右上、左下、右下。点击和按键使用相同判题与继续规则。
- 胶囊展开且鼠标停在内部时也可使用数字键，移开或收起后停止占用按键；菜单打开时暂停答题。
- 词表和学习模式使用应用内下拉菜单，底色、边框和选中底色跟随背景透明度，文字仍独立控制。
- 继续沿用原设置、词表路径和安装位置；安装版及附带三份词表的便携版使用新的 0.1.7 目录，保留旧包。
