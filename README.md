# FuckEnglish

一个常驻桌面顶部的胶囊式背单词工具，让你在工作间隙随手记几个单词。

沿用已有灵动岛的尺寸、主题和开合交互。鼠标悬浮展开词表，查看英文、音标和中文释义，用上一页、下一页翻阅。

## 功能

- 顶部居中的常驻胶囊，收起默认 196 × 32，展开默认 520 × 200（逻辑像素）。
- 胶囊展开后点击“背词”切换到普通背词窗口，沿用设置页样式；可拖动、调整尺寸、最大化和恢复，最小化或关闭后回到胶囊。
- 保留深色、浅色、跟随系统及八套原有主题，支持胶囊、刘海和指示条。
- 读取本地 `.xlsx` 词表，每页 5 个单词，显示英文、音标和中文释义。
- 胶囊顶部切换不同 Excel，自动记住各词表的页码。
- 胶囊顶部切换“浏览 / 英选中 / 中选英”，每轮测试当前整份词表中可测的单词。
- 小测每题四个选项，题目和答案位置默认乱序；选完立即显示对错和正确答案，点击下一题继续，结束显示本轮答对数。
- 普通背词窗口采用居中大题目，英选中显示词表音标；四个答案按两行两列排列，默认无框，悬浮时显示浅框，点击即作答，无需确认。
- 浏览模式可用胶囊内的“顺序 / 乱序”按钮切换，两种顺序分别记住页码；乱序翻页不重新洗牌，重启继续沿用同一顺序。
- 点击英文，将该词显示在收起的胶囊中；翻页后默认显示本页第一个词。
- 自定义词表文件夹，支持浏览、手动填写、打开文件夹和刷新。
- 设置页可另存十列空白 Excel 模板，包含英文、音标、中文释义、常用短语及中英文各三个干扰项。
- 保留悬浮展开、移开延迟收起、点击展开、Esc 收起及动画设置。
- “常规”设置可启用或关闭 Windows 登录启动；启动后在托盘运行，不弹出设置窗口。
- 关闭主窗口后继续在托盘运行，完全退出使用托盘菜单。

## Windows 使用

1. 打开完整的免安装文件夹，双击 `FuckEnglish.exe`，无需先运行安装包。
2. 默认词表位于程序旁的 `words` 文件夹，内含两份各 50 词的示例 Excel。首次启动也可从内嵌示例生成词表；默认位置不可写时回退到用户数据目录。
3. 在设置的“词表文件夹”页选择其他目录，然后点击“应用文件夹”。添加、删除或编辑 Excel 后点击“刷新词表”。
4. 鼠标移到屏幕顶部胶囊上展开，使用顶部下拉框切换词表，底部按钮翻页。浏览时鼠标停留在展开的胶囊内，也可按键盘 **← 上一页、→ 下一页**；移开、收起或进入小测后停用。正在操作下拉框时，方向键保留给选项，点击词表正文后可继续快捷翻页。较长的中文释义可在对应单元格内滚动阅读。
5. 通过齿轮按钮打开设置，修改主题或交互后点击“保存设置”。开机启动默认关闭，打开后下次登录 Windows 自动在托盘运行。
6. 浏览时在底部选择“顺序 / 乱序”。顶部选择“英选中”或“中选英”立即开始当前词表的小测，选择答案后点击“下一题”，最后点击“查看结果”。“再测一轮”会重新打乱题目与选项。
7. 小测中收起胶囊再展开会保留当前题目；切换词表会按当前方向开始新的一轮。切换方向、返回浏览或刷新词表会结束旧一轮。小测进度和成绩仅保留在本次运行内，不保存历史成绩。
8. 想放大背词时，点击胶囊展开栏的“背词”。普通窗口同样支持浏览、顺序 / 乱序和双向小测，方向键可在窗口内翻页；拖动窗口边缘调整大小，右上角可最大化或恢复。点击“回到胶囊”、最小化或关闭都返回胶囊，当前词表、页码和本轮小测进度保持同步。

Windows 需要 Microsoft Edge WebView2 Runtime，Windows 11 通常已预装。当前已构建 Windows x64；其他平台尚未验证。

安装版升级会读取旧版卸载记录中的安装目录，并在原位置更新程序文件；个人设置保留在 `%APPDATA%\FuckEnglish`，词表沿用设置中已有的文件夹。安装时请先退出正在运行的软件。

## Excel 格式

读取每个 `.xlsx` 文件的**第一个工作表**。推荐表头：

| 英文单词 | 音标 | 英文单词释义 | 常用短语 |
| --- | --- | --- | --- |
| pioneer | [ˌpaɪəˈnɪə(r)] | n. 开拓者；先驱者 | a pioneer in science |

其后依次添加六列：`中文干扰项1`、`中文干扰项2`、`中文干扰项3`、`英文干扰项1`、`英文干扰项2`、`英文干扰项3`。设置页“单词模板”导出包含以上十列表头的空白工作簿。

中文干扰项用于“看英文选中文”，英文干扰项用于“看中文选英文”。每组填写三个互不重复、且不等于正确答案的错误选项；正确答案直接使用原有英文和中文释义，不需要重复填写，也不会自动从其他单词抽取干扰项。

小测按方向检查每行数据：缺少某个方向的三个干扰项、干扰项文字重复或与正确答案文字相同，该词跳过该方向的小测，仍可正常浏览。英文比较忽略大小写，重复检查忽略首尾和连续空白；程序不判断释义是否为同义词，请自行保证三个干扰项确实错误。界面显示本轮跳过数，全部不符合时提示补充 Excel 后刷新。

支持列顺序调整，也接受“单词 / 英文”“中文释义 / 中文翻译 / 释义 / 翻译”等常见表头。英文和释义不能为空，缺失的音标显示为 `—`。空行会跳过，Excel 临时锁文件 `~$*.xlsx` 会忽略。常用短语列可填写作为个人记录，目前胶囊不展示该列。旧四列词表继续正常浏览，新增干扰项列也不影响浏览。

暂不支持旧式 `.xls`、加密 Excel、在线表格和自动补全音标；单份词表最多 50000 词，解压后的 Excel 内容最多 64 MB。格式错误会在设置页标明，不会阻止其他有效词表使用。

示例词表由项目提供，释义按原文展示，尚未进行专业校订。

## 设置保存

Windows 通常位于 `%APPDATA%\FuckEnglish\settings.json`，保存外观、开机启动状态、词表目录、当前词表、浏览顺序、乱序种子及两种顺序各词表页码。旧设置和顺序浏览页码继续沿用。开机启动项保存在当前 Windows 用户下，无需管理员权限。卸载本程序时请先自行关闭开机启动，并备份词表和设置。

## 开发与构建

需要 Go 1.27.1+、Bun 和 Windows WebView2 Runtime。

```sh
bun install --frozen-lockfile
bun run generate
bun run dev
```

检查及 Windows 构建：

```sh
go test ./...
go vet ./...
bun run typecheck
bun run test:web
bun run build
```

构建产物位于 `build/windows-amd64/`。前端为 Preact / TypeScript，桌面宿主为 Go / MyGo，Excel 读取使用 Go 标准库，不需要安装 Excel 或 Python。

完整免安装包使用 `scripts/package-windows-portable.ps1`，指定一个尚不存在的输出目录；可通过 `-WordbookDirectory` 指定要随包交付的 XLSX 文件夹。脚本保留 EXE 所需资源、许可与说明，生成免安装目录、ZIP、安装器副本和 SHA256 校验清单，不运行安装器或修改已有交付目录。随包词表不会覆盖用户已有设置中的词表路径。
