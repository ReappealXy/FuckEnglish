# FuckEnglish 0.1.10

本次把胶囊与背词窗口之间的切换改为全局快捷键，并增加自定义设置。

- 默认按 `Alt + Q` 切换胶囊和普通背词窗口，无论鼠标在哪里、当前操作哪个软件都能使用；当前词表、页码和本轮测试进度保持同步。
- 设置的“常规”页新增快捷键入口，可选择 Ctrl、Alt、Shift、Win 与字母、数字或 F1–F12 的组合，至少包含 Ctrl、Alt、Win 中的一种。
- 点击“保存设置”后立即应用，重启继续保留；“恢复默认”先将待保存设置改回 `Alt + Q`。
- 组合键无效或被其他软件占用时显示错误，保留原来的有效快捷键；启动时的注册失败可在设置中查看并更换。
- 单独按 `Q` 不再切换，避免影响其他软件输入；长按切换键不会反复打开和收起窗口。
- 胶囊“背词”和普通窗口“回到胶囊”的提示随已保存的快捷键变化，旧配置自动采用默认 `Alt + Q`。
- 版本升级至 0.1.10，沿用原安装标识、设置和词表目录，以新版本目录交付 Windows 安装版和免安装便携版，保留旧包。实际验证范围见 `docs/VERIFICATION.md`。
