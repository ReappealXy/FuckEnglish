# FuckEnglish 0.1.3

本说明记录 0.1.3 的单词浏览和小测功能，以及 2026-11-05 的界面维护构建。安装包仍显示 0.1.3。

## 单词浏览

- 每页查看 5 个单词，包括英文、音标和中文释义。
- 可在顺序与乱序之间切换。两种浏览方式分别记住页码，乱序后翻页不会重复洗牌。
- 乱序切换现在使用胶囊内的按钮，不会再因为原生下拉菜单伸出胶囊区域而触发自动收起。

![浏览单词和顺序切换按钮](../docs/images/wordbook.png)

## 双向小测

从胶囊顶部选择“英选中”或“中选英”，按当前词表开始一轮小测。每题包含一个正确答案和 Excel 当前行填写的三个干扰项。题目与选项位置随机排列；选择后显示对错和正确答案，手动进入下一题，完成后查看答对数量。

缺少干扰项、干扰项重复或与正确答案相同的单词会跳过对应方向的小测，但仍可正常浏览。小测只读取 Excel 中该行提供的干扰项，不会从其他单词抽取。

## Excel 词表

空白模板包含英文、音标、中文释义、常用短语，以及中文和英文各三个干扰项。按方向填写对应的三项后，该词即可参与相应小测。旧版四列表格仍可浏览。

## 安装与数据

Windows x64 安装版会读取旧版安装位置并在原位置更新。软件设置保存在 `%APPDATA%\FuckEnglish`，自定义词表继续使用设置中原有的文件夹。运行更新安装器前请先退出正在运行的软件。

免安装版解压后可直接运行 `FuckEnglish.exe`。如需改用包内词表，在设置的“词表文件夹”页选择对应的 `words` 文件夹；已有设置不会自动改写词表路径。
