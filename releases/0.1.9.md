# FuckEnglish 0.1.9

本次增加全部 List 学习总览，以及胶囊和普通背词窗口之间的 Q 键切换。

- “测试记录”默认选择“全部 List”，成绩曲线、绿色打卡墙和历史明细同时汇总当前词表目录中的全部记录，仍可切换到某个 List 单独查看。
- 全部 List 的日综合分先计算每个 List 当天各轮平均分，再对当天练过的 List 等权平均。例如 list1 测5轮均为90分、list2 测1轮60分，当天综合分为75分。月综合分再对当月各练习日的综合分等权平均；未练习的日期和词表不计零分。
- 按轮次查看时，每次测试保留独立数据点，按完成时间排列，并显示 List 名称、时间和该 List 当天次数。
- 全部 List 热力图按当天所有 List 完成的总轮数显示颜色，保留月历与全年视图；点击日期可查看当天练过的词表份数和各轮明细。
- 总览显示完成轮数、练习天数、练习词表覆盖数和综合平均分。历史明细增加 List 列，能区分不同词表同一天的重复练习。
- 在普通背词窗口内按 Q 返回胶囊；鼠标停在胶囊上时，收起和展开状态均可按 Q 打开普通背词窗口，当前词表与测试进度继续同步。
- Q 键仅响应一次普通按键，输入框、菜单操作、组合键和长按重复输入不会触发窗口切换。
- 版本升级至 0.1.9，沿用原安装标识、设置和词表目录，以新版本目录交付 Windows 安装版和免安装便携版，保留旧包。
