# FuckEnglish 0.1.8

本次增加测试成绩记录、按日和按月的成绩趋势，以及月／年绿色打卡墙。

- 每轮英选中测试按 50 题基准计分，每个答对的词 2 分，答错和选项缺失而跳过的词计 0 分；有跳过词也正常登记。例如 40 对、8 错、2 个跳过，记为 80 分。
- 最后一题作答成功后自动保存一次成绩，无需等到点击“完成”；未完成轮次不登记。同一天重复测试分别保留，显示具体时间、当天次数和该 List 累计轮次。
- 设置新增“测试记录”，可按 List 查看按轮次、按日和按月的成绩曲线。日分数是当天各轮平均分，月分数是当月各练习日日均分的平均值，缺测日期留空。
- 绿色打卡墙支持月历与全年视图。一格一天，完成 1、2、3、4 轮及以上分别显示由浅到深的四档绿色；点击日期查看当天成绩。
- 历史成绩保存在所选词表目录下的 `测试记录/records.json`，首次登记时自动创建，重启后保留；搬动词表时可把“测试记录”文件夹一起带走。
- 数字 1 左边的反引号键（`Backquote`）可在答错后下一题，末题作答后完成；未答不跳题，答对后的自动下一题继续保留。胶囊和普通背词窗口均支持。
- 重新打开设置时回到“词表文件夹”页并滚动到最顶端；当前 List 与正在测试的题目保持同步。
- 沿用原安装位置、设置与词表路径，使用新的 0.1.8 目录交付 Windows 安装版和免安装便携版，保留旧包。
